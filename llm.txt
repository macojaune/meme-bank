# Importer une vidéo dans MemeBank

Installe la CLI MemeBank 0.5.0 depuis le dépôt avec Node.js 22 ou plus récent.
Depuis la racine du dépôt, exécute `npm install -g ./cli`, puis
`memebank-upload --help`.

## Connexion à DEV

Définis `MEMEBANK_URL=https://memebank-dev.marvinl.com`.
Injecte le jeton d’import depuis ton gestionnaire de secrets dans
`MEMEBANK_UPLOAD_TOKEN`. Le jeton suffit sur DEV. Supprime l’ancienne variable
`MEMEBANK_DEV_BASIC_AUTH` de ta configuration.
Garde le jeton hors des commandes, fichiers de projet et journaux.

L’opérateur MemeBank crée un jeton avec les droits d’import et de publication
pour le compte autorisé.

```sh
node ace video:upload-token issue <user-id> --output /chemin/prive/token --publish
```

Le jeton expire au bout de 30 jours. L’opérateur peut le révoquer avec
`node ace video:upload-token revoke <user-id> --id <id>`.

## Exemples

L’assistant récupère un MP4 compatible selon ses règles, puis passe le
fichier local à la CLI. Pour un import minimal, exécute la commande suivante.

```sh
memebank-upload ./video.mp4
```

Ajoute le titre et la transcription quand ils sont fournis.

```sh
memebank-upload ./video.mp4 --title "Titre donné par l’utilisateur" --transcript-file ./transcription.txt
```

`--name` est un alias de `--title`. Le fichier de transcription doit contenir
du texte brut UTF-8. Utilise `--transcript 'texte'` pour un court extrait
ou `--transcript-file` pour un texte multiligne.

La commande publie la vidéo directement dans la banque commune. Les
commandes existantes avec `--publish` produisent le même résultat. Un
titre omis reste vide. L’interface affiche « Sans titre ». Une transcription
fournie devient la première révision, marquée « Importée ».

## Fichiers pris en charge

Pour l’usage par fichier local, le format recommandé est le MP4. L’API
accepte les fichiers MP4, WebM, Ogg et AVI jusqu’à 50 Mio. Le titre est
limité à 255 caractères et la transcription à 64 Kio. L’envoi dispose de
120 secondes. La CLI envoie les octets du fichier d’origine. Si l’API
refuse le format ou la taille, récupère un fichier compatible avant envoi.

MemeBank rend le fichier disponible dès son stockage. L’import CLI ne
programme aucune conversion, transcription ou génération de vignette.
Le formulaire web conserve son circuit de traitement automatique.

## Résultat et relance

Le CLI écrit un objet JSON sur stdout en cas de succès.

```json
{"videoId":"93c4bd71-0fc7-45b9-8bff-05d2862c381d","replayed":false,"isPublished":true}
```

`replayed: true` indique que MemeBank a reconnu l’import. Par défaut,
le CLI calcule une clé SHA-256 à partir du contenu de la vidéo, du titre,
de la transcription et de la demande de publication. Pour relancer un envoi
interrompu, reprends les mêmes octets et options. Si tu avais fourni
`--idempotency-key`, réutilise la même valeur avec les mêmes données.

En cas d’erreur, le CLI quitte avec le code 1 et écrit un objet JSON
`{"error":{"code":"…","message":"…","status":401}}` sur stderr.
Le statut HTTP est présent quand le serveur a répondu.

- `UNAUTHORIZED` : vérifie le jeton et l’accès DEV.
- `FORBIDDEN` : utilise un jeton avec `video:upload` et `video:publish`.
- `PUBLICATION_NOT_CONFIRMED` : vérifie la présence de la vidéo dans la banque.
  Le succès de l’envoi ne confirme pas sa publication.
- `409` : vérifie la clé d’idempotence et les données de l’import.
- `400`, `413` ou `422` : vérifie la taille, le format vidéo et les métadonnées.
- `503 private_storage_unavailable` : le stockage privé reste à configurer côté MemeBank.

Pour un autre client HTTP, utilise `POST /api/agent/video-import`,
`Authorization: Bearer <jeton>` et `Idempotency-Key`. Le corps multipart contient
`video` et `publish=true` pour une publication directe, avec `title` et
`transcript` en option.
Sur le domaine DEV ci-dessus, réserve `Authorization: Basic …` à l’accès DEV
et transmets le jeton brut dans `X-MemeBank-Upload-Token`.
